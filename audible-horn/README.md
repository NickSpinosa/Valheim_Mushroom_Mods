# Audible Horn

A craftable Signal Horn for Valheim. Sounding it makes a Horn Call that every
player within Hearing Range can hear, so people can find each other on a no-map
server.

Requires [MushroomSync](../MushroomSync/README.md) on every client and on the
dedicated server.

See [docs/](docs/) — [docs/CONTEXT.md](docs/CONTEXT.md) is the design and the
glossary, [docs/tickets/](docs/tickets/) is the build plan.
